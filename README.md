# Viremo

Viremo is a full-stack watch tracker for movies, series, and anime. It includes account login, a protected diary dashboard, CRUD entry flows, TMDB-powered search, and shareable public profiles.

## Stack

- Next.js 16
- React 19
- Prisma 7
- PostgreSQL / Supabase
- NextAuth
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Notes

- Environment variables live in `.env`
- Prisma schema lives in `prisma/schema.prisma`
- Main app routes live in `app/`
